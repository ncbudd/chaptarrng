The FreeBSD installation guide now lists the system dependencies required by the .NET 10.0.15 standalone archive. MIT krb5 must be version 1.22.3 or newer from a current package repository or updated port; earlier versions are affected ([FreeBSD VuXML advisory](https://vuxml.freebsd.org/freebsd/8dc02503-dd51-11f1-a654-f8b46a88f42c.html)).
